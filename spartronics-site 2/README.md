# Spartronics – FRC Team 2141 · Website

Static site for **Spartronics, FIRST Robotics Competition Team 2141** (De La Salle & Carondelet High Schools, Concord, CA).
Plain HTML + CSS + vanilla JS, generated by a tiny Node script with no dependencies. Ready for Vercel.

```
spartronics-site/
├── build.js              ← renders src/pages/*.js through the shared layout into dist/
├── vercel.json           ← Vercel config (build command, output dir, clean URLs, cache headers)
├── package.json
├── src/
│   ├── site.js           ← ★ site settings + the menu (ONE place for name, email, socials, Formspree, donate URL)
│   ├── layout.js         ← <head>, header, nav, mobile menu, footer
│   ├── components.js     ← reusable components (PageTitle, Panel, MediaText, Slider, Accordion, …) + icons + logo
│   ├── pages/            ← one JS file per section; each exports page objects {path, title, description, body}
│   └── assets/
│       ├── css/styles.css   ← design tokens + all styles (~38 KB)
│       ├── js/main.js       ← nav, sticky header, sliders, forms, JSON rendering (~16 KB)
│       ├── data/            ← ★ team.json · seasons.json · robots.json
│       └── img/             ← logo SVGs, favicon, OG image (+ your photos go here)
├── scripts/
│   ├── check-links.js    ← verifies every internal link/asset resolves + one <h1> per page
│   ├── screenshot.js     ← screenshots every page at 1440 and 390 px and flags horizontal overflow
│   └── render-icons.js   ← regenerates favicon.png / apple-touch-icon.png / og-default.png from the SVGs
└── dist/                 ← build output (what Vercel serves). Pre-built copy included.
```

## Deploy to Vercel (3 ways)

**A. Git (recommended).** Push this folder to a GitHub repo, then in Vercel: *Add New → Project → Import*.
`vercel.json` already tells Vercel to run `node build.js` and serve `dist/`. Every push redeploys.

**B. Vercel CLI.** `npm i -g vercel`, then `vercel` in this folder. Accept the defaults (it reads `vercel.json`).

**C. Drag and drop.** Run `node build.js` locally and drag the `dist/` folder onto vercel.com/new. (Loses the auto-rebuild; fine for a one-off.)

Then: *Project → Settings → Domains* to attach the team's domain, and update `url` in `src/site.js` so canonical URLs and the sitemap match.

Local preview: `npm run dev` (builds and serves `dist/` at http://localhost:3000).

## Editing content

| Want to change… | Edit this |
|---|---|
| Team email, social links, tagline, Formspree ID, donate URL, domain | `src/site.js` |
| Menu items / order | `menu` array in `src/site.js` (header, mobile menu and current-page highlighting all follow it) |
| Roster | `src/assets/data/team.json` |
| Season results / history cards | `src/assets/data/seasons.json` (newest first; `highlights` become badge chips) |
| Robots | `src/assets/data/robots.json` |
| Page copy | the matching file in `src/pages/` (home, about, join, outreach, resources, support) |
| Colors, type, spacing | tokens at the top of `src/assets/css/styles.css` |

After any edit: `node build.js` (or just push — Vercel builds for you).

### Swapping in real photos
Every image is a labeled placeholder SVG generated at build time (`/assets/img/placeholders/<id>.svg`).
To replace one: drop your photo in `src/assets/img/` and change that `img(...)` call's output — the simplest way is to edit the `<img src>` in the page file, e.g.

```js
// before
img('hero-team', 'Team group photo with robot outdoors', 1600, 900, 'Alt text…')
// after
'<img src="/assets/img/team-2026.jpg" width="1600" height="900" alt="Spartronics team with the 2026 robot" loading="eager">'
```
Keep `width`/`height` so nothing shifts while loading. Use WebP or JPEG; keep hero ≤ 300 KB.

For the roster and robots, set `"photo"` / `"image"` paths in the JSON files instead.

### Logo
`src/assets/img/logo-horizontal.svg` and `logo-horizontal-reverse.svg` are placeholders (a Spartan helmet with circuit traces, "—2141—", and the wordmark). The header/footer logo is drawn inline in `src/components.js → logo()` so it uses the page's Poppins font. **[EDIT]** replace with the official team logo: either update `logoMark()`/`logo()` or swap the inline SVG for `<img src="/assets/img/logo-horizontal.svg">`. Rerun `node scripts/render-icons.js` after changing `favicon.svg`.

### Forms
Contact, "I'm Interested" and the parent sign-up all post to **Formspree** (Vercel has no built-in forms). Create a form at formspree.io, paste the endpoint into `formspreeEndpoint` in `src/site.js`. Until then the forms show a friendly "not connected yet — email us" message instead of failing silently. Each form has a honeypot field (`_gotcha`) and inline validation.

## Design system (Spartronics green edition)

Mirrors the Red Tie Robotics look (Poppins, centered 1160 px column, dark nav bar as a block inside the container that goes full-bleed when sticky, dark footer, 1 px rules, 2 px bordered gray panels, flat and boxy, no shadows) with De La Salle green in place of red.

| Token | Hex | Use |
|---|---|---|
| `--sp-green` | **#0A4D2B** | brand green: page titles, names, accents, links, logo *(team-supplied)* |
| `--sp-green-dark` | **#00371A** | hover / pressed *(team-supplied)* |
| `--sp-green-cta` | #0F6B3B | primary buttons (slightly brighter so they read as buttons, like Red Tie's #E8311F vs #E3000B) |
| `--sp-green-bright` | #3DBF7A | accent on dark backgrounds: stats numbers, nav current-page underline, footer headings, History pill |
| `--sp-green-tint` | #E8F1EC | light wash: chips, the featured tier, highlighted panels |
| `--sp-gold` | #C9A84C | secondary Spartan-gold accent — hero eyebrow and OG image only (decorative; swap if the school's gold differs) |
| `--sp-ink` | #0B1210 | nav bar, footer, stats band (near-black with a green cast instead of pure black) |
| `--sp-black` | #000000 | rules and panel borders |
| `--sp-text` / `--sp-text-strong` / `--sp-muted` | #3F4542 / #171A18 / #6A736F | body, emphasis, captions |
| `--sp-surface` / `--sp-surface-2` | #F4F6F5 / #F7F8F7 | panels, accordion bars |

All text/background pairs meet WCAG 2.2 AA (white on #0A4D2B ≈ 10:1; white on #0F6B3B ≈ 6.6:1; #3DBF7A on #0B1210 ≈ 8:1).
